Device Inventory can read a Google Workspace mailbox and turn each new email into a ticket, then send your replies from that address. Test it with a separate mailbox first (for example helpdesk-test@thehudsonschool.org); switching to helpdesk@ later only means changing the address below and connecting again.

Setting it up (one time)

  1. Create the mailbox. In the Google Admin console, add a user such as helpdesk-test@thehudsonschool.org, then sign in to it once so it's ready.
  2. Create a Google Cloud project. Signed in with your admin account, open console.cloud.google.com and create a project (for example "Help Desk") in your organization.
  3. Turn on the Gmail API: APIs & Services → Library → search "Gmail API" → Enable.
  4. Create the sign-in client. Open Google Auth Platform (older name: OAuth consent screen):
    • Get started: app name "Device Inventory Help Desk", your email as support and contact email, and Audience: Internal (only your school's accounts can use it, and no Google review is needed).
    • Clients → Create client → Application type Desktop app → Create, then Download JSON.
  5. Here: enter the mailbox address, choose the downloaded .json file, and click Save.
  6. Click Connect mailbox and sign in as the help desk mailbox (not your own account), then click Allow. Google may warn that the app is unverified; that's expected for an internal app.
  7. Tick "Check this mailbox", Save, and send the mailbox a test email from your own account. Within a couple of minutes (or click Check now) it appears on the Help Desk page.

What it can do: read, label and send mail in that one mailbox only; it can't delete mail or open any other account. The sign-in is saved in gmail.json next to the inventory (not in backups). If your Workspace limits third-party apps, allow this app under Admin console → Security → API controls → App access control. Sign-in returns to {{ redirect_uri }}, so connect from the computer that runs Device Inventory. Disconnect here, or remove access at myaccount.google.com/permissions while signed in as the mailbox.
