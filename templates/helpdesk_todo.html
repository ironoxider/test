In Todoist (web or desktop app): your avatar → Settings → Integrations → Developer → Copy API token. The board shows that account's tasks, including projects shared with it, so a shared "IT" project works well. The token stays on this computer and isn't put in backups.

Written the same way as a filter in Todoist, e.g. #IT & (today | overdue | no date), @hardware or assigned to: me. With a filter, the project choice above is ignored (put #Project in the filter instead).
